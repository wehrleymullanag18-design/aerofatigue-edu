# 项目事实

## 可由原始资料确认

- 项目申请书名称为“预应力-温度循环疲劳仪的改造与升级”，项目编号 2022CXJJ20。
- 资料描述的系统由温度循环疲劳测试仪、上位机/PC 终端、数据处理与显示、电阻应变仪等构成。
- 工作原理为：上位机设置温度载荷、循环次数和预紧力；高温槽与低温槽准备环境；双自由度作动平台带动试样在两槽间循环；传感器与应变仪采集数据。
- 实体照片确认了整机、操作面板、急停按钮、报警指示灯、高低温控制器、实验加载区、固定板、快速更换夹具、双自由度作动机构和循环制冷组件的存在。
- 申请书目标指标写明：高温环境 80℃、低温环境 10℃、温度误差不高于 2%、应力误差不高于 2%、循环次数误差 0%。这些是项目文件中的目标/描述，未在本网站开发中独立复验。
- `materials/data/` 明确当前暂无真实实验数据。
- `materials/video/` 明确当前暂无真实设备视频。

## 资料状态

- 已实现：本地虚拟教学平台、设备认知、安全联锁、模拟数据、评分、报告、答辩展示。
- 正在升级：真实设备数据接口、真实视频、更加精确的热点坐标与教学题库。
- 未来验证：真实设备量程、误差、寿命预测模型、工程检测结论以及扩展的腐蚀/湿度/酸碱度加速环境。
