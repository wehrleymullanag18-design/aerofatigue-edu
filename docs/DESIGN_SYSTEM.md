# 设计系统

视觉方向为“航空维修工卡 × 工程蓝图 × 实体实验台”。

- 页面背景：暖灰白 `#F2F1ED`；主面板 `#FCFCFA`；铝灰 `#DDE1E6`；深墨 `#141A22`。
- 功能色：航空蓝 `#174A8B`；高温橙 `#E86F2A`；低温青 `#2B8CA3`；正常绿 `#258260`；警告黄 `#D99B28`；故障红 `#BD3434`。
- 航空蓝只承担导航、当前步骤和主要操作；高温、低温、正常、警告、故障严格使用各自语义色。
- 页面外层采用浅色工程工作区，只有真实设备数字实验区和必要仪表区域使用深墨底。
- 标题使用系统中文无衬线字体，控制在 30–48px；数据数值使用系统等宽字体。
- 普通面板圆角 6–10px，按钮 6–8px；标签采用矩形工卡，不使用胶囊。
- 边框为 1px 灰色或深墨细线，阴影仅用于轻微层级，不使用发光阴影。
- 用工程编号、刻度、坐标、细线标注和真实设备照片组织信息，避免英文大写标题与装饰性科技图形。
- 图表使用浅色坐标区、明确单位与高温/低温语义色；模拟数据声明始终可见。
