# AeroFatigue Edu

预应力—温度循环疲劳虚拟实验教学平台。平台面向大学生创新创业项目答辩、实验教学、操作训练与安全考核，使用真实设备资料建立结构认知，再通过本地虚拟控制台完成规范操作、数据理解、评分与报告。

> 重要声明：第一版不连接真实仪器，不发送真实控制指令。所有传感器数据、曲线、故障、评分和报告均为教学模拟，不代表正式实验结论。

## 已实现功能

- 课程首页：项目定位、四种模式、真实设备证据、学习目标与建设状态。
- 学习模式：18 个设备部件、照片热点、详情面板、学习进度和随机小测验。
- 练习模式：15 步严格准备流程、具体操作提示、日志和错误复盘。
- 考核模式：安全联锁、操作分、安全分、错误记录和通过规则。
- 虚拟控制台：正常/警告/故障预设、2.5D 动画、实时曲线、暂停、继续、急停、复位。
- 数据分析：确定性模拟数据、温度—预应力—应变联动与科学边界说明。
- 实验报告：A4 打印、JSON 导出、成绩 CSV 导出、教师评语区。
- 教师模式：本地任务设置、评分规则、成绩概览、日志和题库预览。
- 答辩模式：10 章演示、3/5/8 分钟路线、方向键、空格暂停、ESC 退出、全屏。
- 真实数据与真实视频接口：安全占位，不伪造缺失素材。

## 哪些内容是真实资料，哪些是模拟

真实资料来自 `materials/`：

- `device-overview.jpg`：整机、上位机、温控、加载区和制冷组件。
- `control-interface.jpg`：控制界面、操作面板、急停、报警灯和温控器。
- `loading-module.jpg`：固定板、快速更换夹具和双自由度作动机构。
- `project-application.pdf`：系统原理、设计方案、目标指标与工作流程。

辅助图 `system-overview-infographic.png` 只用于讲解，页面明确标注“辅助设计图”。所有实时数据、曲线、动画、故障、评分和实验结果均为教学模拟。

## 环境要求

- Windows 10/11
- Node.js 20.9 或更高版本
- 首次安装依赖时需要网络；安装完成后主要功能可本地运行
- 推荐浏览器：Chrome 或 Edge

## 第一次安装与双击启动

1. 安装 Node.js：https://nodejs.org/
2. 打开本项目文件夹。
3. 双击 `start.bat`。
4. 如果依赖尚未安装，启动器会自动执行安装。
5. 浏览器将打开 `http://localhost:3000`。
6. 启动期间不要关闭黑色命令窗口。

## 命令启动

在项目文件夹打开 PowerShell：

```powershell
npm install
npm run dev
```

访问 `http://localhost:3000`。也可使用本项目锁定的 pnpm：

```powershell
pnpm install
pnpm dev
```

## 四种模式怎么进入

- 学习模式：首页点击“学习模式”，进入设备认知和小测验。
- 练习模式：首页点击“练习模式”，按提示完成虚拟实验。
- 考核模式：首页点击“考核模式”，系统记录顺序与安全错误。
- 答辩模式：首页点击“答辩演示”，或直接访问 `/presentation`。

## 完整实验操作

依次点击：连接设备 → 归零 → 打开防护门 → 选择试样 → 选择夹具 → 安装 → 夹紧 → 关闭防护门 → 设置参数 → 预热 → 预冷 → 确认环境 → 施加预应力 → 状态检查 → 启动实验。

- 暂停：实验运行后点击“暂停”，数据与动画冻结。
- 继续：暂停后点击“继续”。
- 急停：点击红色“紧急停止”，系统立即停止；必须点击“系统复位”，不能直接继续。
- 故障：在控制台顶部选择“警告”或“故障”预设后运行。
- 安全联锁：点击“演示：防护门未关尝试启动”，系统阻止操作并记录扣分。

## 成绩、报告和导出

- 成绩：控制台右侧查看实时总分和安全错误；教师模式查看本地记录。
- 报告：完成演示实验后点击“打开实验报告”。
- JSON：报告页点击“导出 JSON”，或控制台数据区点击 JSON。
- CSV：报告页点击“导出成绩 CSV”；控制台数据区可导出模拟数据 CSV。
- PDF：报告页点击“浏览器打印 / 保存 PDF”，在浏览器打印窗口选择“另存为 PDF”。

## 如何维护素材与规则

### 替换设备照片

不要修改 `materials/`。将确认后的新照片复制到 `public/assets/images/original/`，保持文件名，或同步修改 `src/data/device-parts.ts` 中的图片路径。

### 修改设备热点

编辑 `src/data/device-parts.ts`。`x`、`y` 是照片宽高的百分比坐标。没有可靠位置时删除坐标并保留 `status: "位置待确认"`。

### 补充真实数据

阅读 `docs/REAL_DATA_REPLACEMENT.md`。正式数据至少需要时间、高低温槽温度、试样温度、预应力、应变和循环次数，并先检查单位、缺失值和来源标签。

### 补充真实视频

阅读 `docs/VIDEO_REPLACEMENT.md`。把审核后的 MP4 放入 `public/assets/videos/`，推荐使用：

- `device-overview.mp4`
- `specimen-installation.mp4`
- `cycling-motion.mp4`
- `control-interface-demo.mp4`

### 修改题库、评分和参数

- 题库：`src/data/questions.ts`
- 评分：`src/data/scoring.ts`
- 流程与参数说明：`src/data/teaching.ts`
- 状态机：`src/lib/state-machine/machine.ts`
- 模拟模型：`src/lib/simulation/engine.ts`

## 常见问题

- 双击后提示没有 Node.js：安装 Node.js 20.9 以上版本后重试。
- 依赖安装失败：检查网络；关闭可能占用 `node_modules` 的安全软件后重试。
- 3000 端口被占用：关闭之前的开发窗口，或在 PowerShell 使用 `npm run dev -- -p 3001`。
- 页面看不到数据：必须按准备流程启动实验；未启动时图表保持等待状态。
- 按钮是灰色：鼠标悬停可查看当前状态不满足的原因。
- 图片或视频缺失：图片使用明确备用区；视频页面显示“真实设备视频待补充”，不会加载破损播放器。

## 科学声明

本平台不是材料疲劳寿命计算模型，不替代真实设备操作规程、实验室安全培训、检测报告、认证或工程验证。申请书中的 80℃、10℃、误差等内容按“项目文件目标值”展示，未在本网站开发中独立复验。

## 答辩推荐路线

### 3 分钟

首页定位 → 真实设备照片 → 一个设备热点 → 安全联锁 → 短实验曲线 → 报告。

### 5 分钟

首页 → 设备认知 → 完整准备流程 → 暂停/继续 → 安全联锁 → 急停/复位 → 数据与报告。

### 8 分钟

使用 `/presentation` 的十章模式完整展示；穿插设备小测验、正常/警告/故障预设、教师模式、真实数据和视频接口。
